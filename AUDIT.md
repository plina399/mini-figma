## Что проверялось

- Секреты: `git grep` по рабочему дереву + `git log -G/-S` по всей истории (паттерны
  `api_key|secret|token|password|ghp_|sk-|AKIA…|BEGIN PRIVATE KEY`). **Секретов не найдено.**
  В `deploy.yml` используется штатный `id-token: write` для OIDC-деплоя Pages — это не секрет.
- Критические баги: разбор всех обработчиков указателя/клавиатуры в `src/App.jsx`.
- Дубли и мёртвый код: сверка всех CSS-классов и JS-функций с разметкой (`git grep`).
- Стили/разметка: `src/index.css`, `src/App.css`, глобальные селекторы, токены.
- Потеря данных: история (undo/redo), коллаборация, z-порядок слоёв.
- Уязвимости: XSS через `dangerouslySetInnerHTML`/`innerHTML` не используется;
  BroadcastChannel — одноранговый канал в пределах origin, секретов не передаёт.
- Мусорные файлы: `git grep` по использованию каждого ассета и корневого файла.
